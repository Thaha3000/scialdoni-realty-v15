# Scialdoni Realty – Version 15

Built from the supplied Version 14 files. This revision addresses only the broken
MLS PIN embed and the preferred homepage search bar; other pages and photos remain
as in V14.

## Changes

- Restored the classic homepage SEARCH HOMES / GET A HOME VALUATION tabs and
  the editable address, city, ZIP, or neighborhood text field.
- Removed the oversized EXPLORE LIVE LISTINGS homepage button.
- Removed the large broken iframe from search.html. Replaced it with a compact
  accessible property search form and a reliable direct link to Ed's MLS PIN IDX.
- Desktop and mobile styles reviewed.

## Important limitation

MLS PIN's current free public link is:

https://idx.mlspin.com/MLS.IDX/Search?AgentId=C9501243

The free IDX URL does not expose a documented interface for submitting a city or
street address entered on another website. Typing in the Scialdoni Realty form
and choosing SEARCH opens the live MLS PIN site in a new tab. Where the user's
browser permits, the entered location is copied to the clipboard, ready to
paste into MLS PIN's town/address search. If clipboard access is unavailable,
the location can be typed into MLS PIN directly. We do NOT imply a filtered MLS
results page has been generated by the Scialdoni Realty form.

MLS PIN's public frame option is documented, but the live embed displayed a
broken page in the browser screenshots supplied by the site owner. To avoid an
unusable large empty panel, this version uses the working link instead.
